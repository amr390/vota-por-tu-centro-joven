# Proyectos Web - GitHub Pages

Repositorio con proyectos web de prueba alojados en GitHub Pages.

## Proyectos Incluidos

- **Sistema de Votación Centro Joven**: Aplicación web para votación ciudadana
- **Página de Prueba**: Landing page principal

## Ver en Vivo

🌐 **URL**: `https://TU_USUARIO.github.io/TU_REPOSITORIO`

## Configuración GitHub Pages

1. Ve a Settings del repositorio
2. Scroll hasta "Pages"
3. Source: Deploy from a branch
4. Branch: main
5. Folder: / (root)

## Archivos

- `index.html` - Página principal
- `votacion_centro_joven.html` - Sistema de votación
- `style_votacion.css` - Estilos del sistema de votación
- `script_votacion.js` - JavaScript del sistema de votación
